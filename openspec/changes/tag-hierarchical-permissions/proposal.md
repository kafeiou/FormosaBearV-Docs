# Proposal: 階層式標籤權限與中斷繼承（Windows 式權限）

## Why

在目前的 FormosaBearV / Teedy 架構中，標籤權限（ACL）僅能單獨作用於個別標籤與直接打上該標籤的文件，標籤與標籤之間無法繼承父層權限。在組織常見的多層目錄結構（如「部門 / 專案 / 年度」）下，管理者必須為每個子標籤逐一手動賦予相同群組的權限，不僅維護負擔龐大，更易發生權限漏設的人為疏失。此外，當某些敏感子標籤（如「高階主管薪資」）需要獨立隔離時，亦缺乏阻絕父層權限滲透的機制。

為了實現如同 Windows 檔案總管（NTFS ACL）般直覺、嚴密且具彈性的企業級權限管理，本提案旨在引入「階層式權限向上回溯繼承」與「中斷繼承（Block Inheritance）」機制。

## What Changes

- **階層式權限向上回溯繼承（Hierarchical Inheritance）**：
  - 子標籤在預設狀態下自動向上繼承其父標籤、祖先標籤的所有權限（READ 讀取與 WRITE 寫入權限均完整向下繼承）。
  - 支援權限疊加原則：子標籤除繼承父層權限外，亦可於本層額外加開特定使用者或群組之權限。
- **中斷繼承開關與權限轉換（Block Inheritance & Permission Transition）**：
  - 標籤實體新增「繼承上層權限」開關（`TAG_INHERIT_ACL_B`，預設為 `true`）。
  - **中斷繼承時**：取消勾選「繼承上層標籤權限」時，系統預設自動將上層權限複製為本層自訂權限，供管理者直接微調刪減，簡化操作流程。
  - **恢復繼承時**：日後重新勾選繼承時，系統直接清除本層自訂權限，完全由上層繼承主導，避免殘留過期權限。
  - 當中斷繼承時，該標籤成為獨立安全邊界，向上遍歷立即終止，上方祖先權限無法穿透。
- **無父層權限時的樹狀階層結構呈現（Container Navigation）**：
  - 若某子標籤獨立授權給使用者，但該使用者無上層父標籤權限，左側標籤樹仍顯示父標籤名稱作為樹狀路徑容器（以灰色不可點擊方式呈現，且不顯示父層文件），以完整保留階層架構。
- **多重標籤文件權限判定（聯集原則）**：
  - 當一份文件同時貼附多個標籤時，採取寬鬆聯集原則：只要該文件的其中任何一個標籤（透過其有效祖先鏈）具備存取權限，使用者即可存取該文件。
- **標籤管理 UI 呈現分流與視覺標記**：
  - 於標籤編輯對話框（`tag.edit.html`）新增「繼承上層標籤權限」核取方塊。
  - 於權限清單中分列呈現「從上層繼承的權限」（註明來源父標籤，無法在此直接刪除）與「本標籤專屬權限」（可新增/刪除）。
  - 於標籤管理樹與標籤瀏覽樹（`tag.admin.html`, `tag.html`）中，針對中斷繼承的獨立標籤顯示鎖頭圖示（`fa-lock text-warning`），讓安全邊界一目了然。
- **資料庫遷移與向下相容**：
  - 建立 DB Migration v35（`dbupdate-035-0.sql`），於 `T_TAG` 新增 `TAG_INHERIT_ACL_B BOOLEAN DEFAULT TRUE NOT NULL`。
  - 既有標籤與備份檔還原預設維持繼承狀態，完全相容舊版資料。

## Capabilities

### New Capabilities
- `tag-permissions`: 階層式標籤權限向上回溯繼承、中斷繼承安全隔離、無父層權限時的路徑容器呈現、多重標籤文件存取聯集判定，以及標籤權限 UI 鎖頭標記與繼承開關。

## Impact

- **資料庫 (DB)**: `T_TAG` 資料表新增 `TAG_INHERIT_ACL_B` 欄位（DB Migration v35）。
- **後端核心 (Core)**:
  - `Tag.java` 與 `TagDto.java` 新增 `inheritAcl` 屬性。
  - `TagDao.java` 增加有效祖先鏈查詢與帶權限的標籤清單過濾，支援路徑容器標籤辨識。
  - `AclDao.java` 與 `LuceneIndexingHandler.java` 升級為支援標籤祖先權限與多標籤聯集檢查（包含 READ 與 WRITE 繼承）。
- **後端 REST API (Web)**:
  - `TagResource.java`: `add` 與 `update` 端點接收 `inherit_acl` 參數；提供複製父層 ACL 與清除自訂 ACL 之處理邏輯。
- **前端 Web (WebApp)**:
  - `tag.edit.html`、`Tag.js`: 權限區塊增加繼承開關，並區分顯示繼承權限與自訂權限。
  - `tag.admin.html`、`tag.html`: 樹狀節點新增隔離鎖頭圖示，以及未授權父標籤之灰色容器樣式。
  - 多國語系（`zh_TW.json`, `zh_CN.json`, `en.json`）新增相關提示詞彙。
